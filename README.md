# Nurture

A full-stack application with NextJS frontend and Express backend.

## Structure

- `web/`: NextJS application (frontend)
- `server/`: Express server (backend)

## Development

### Frontend

```bash
cd web
npm run dev
```

### Backend

```bash
cd server
npm start
```

## Deployment

This project is configured for Vercel deployment. Push to a GitHub repository and connect it to Vercel for automatic deployment.
